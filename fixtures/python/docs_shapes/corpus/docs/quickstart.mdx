The `pkg.Server` class is the entry point; a `Server` has tools.

## Install

Call `make_server()`, then `Server.tool` to register a tool (`pkg.Server.tool` in full). Another
library's `other.Server.tool` is not this one.

<Note>
Components hold code blocks too:

```python
from pkg import Server

server = Server()
```
</Note>

### Details

See [the reference](/reference/pkg-core#server) for `pkg.core.Server`. The `logger` is not an API
mention, but make_server in prose is a lexical candidate. Ünïcödé text keeps byte offsets honest.

## Limits

Registering with `pkg.Server.tool` twice keeps the last.

<Warning>
`pkg.Server.tool` does not validate `fn`.
</Warning>

## Stopping

`pkg.Server.stop` stops the server — gracefully, by default.

<ParamField body="timeout" type="float">
Seconds to wait before stopping.

<Warning>
A `timeout` of zero stops at once.
</Warning>

<ParamField body="grace">
A nested field is not a parameter of its own.
</ParamField>
</ParamField>

<ParamField body="force">
Not a parameter of the operation.
</ParamField>

<ParamField body="drain">
The docstring's description comes first.
</ParamField>
