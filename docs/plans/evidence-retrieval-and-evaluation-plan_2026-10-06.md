attributed roots → primary/context parts → semantically partitioned windows and exact bindings →

judges the result against independent task expectations and diagnoses the first material loss.

### 2.1 Evidence construction and delivery contract

Roots include callable and non-callable definitions, public exposures, effective/source options,
standalone source/documents, scenarios and deployment/release material. Source inspection
resolves definitions separately from public access provenance. Ambiguous or unavailable definitions
remain qualified alternatives; no forced single callable root.

A part states whether it is primary information or interpretation context, its original byte
mapping and its applicable scope. A window references its ordered parts and immutable render/
partition policy. Its bindings identify only targets nominated by primary material with an
appropriate association basis. A setup-only import or heading mention is context/navigation,
not another exact nomination. Context dependencies retain enclosing predicates, option identity,
signature/variant, setup and qualifications. All joins retain release and compatible invocation/
configuration context; physical adjacency alone does not establish semantic support.

Initial partition policy prefers approximately 1024 **complete encoder-input** tokens, hard
maximum 2048. Headers, mandatory context and special tokens count. Split at supported syntax/
document boundaries, without truncation. Indivisible oversized content has explicit lexical-only/
partial-vector availability and original expansion. Exceptional larger windows need a named task
and a separately identified admission policy; 4096 vector dimensions do not imply a 4096-token cap.

Load local tokenizer assets once per actual encoder realization; compose rendered-input UTF-8
offsets with original maps. Python character offsets and special-token empty ranges are not
source spans. Endpoint tokenization is a parity control, not a per-tentative-window round trip.

Production EvidenceDemand expresses desired information, context and delivery/journey limits,
not private expected answers. Preserve existing route defaults when no demand is supplied.
PacketEvidenceMap describes actual delivered structured fields/text spans, source anchors,
context, qualification and omission/expansion state. It is observable metadata checked by the
evaluator, not a self-authorizing correctness certificate. An opaque condition/default ID without
its readable meaning cannot count as immediate delivery.

### 2.2 Full values and deliberate analytical policy — F02

Select **one immutable normalized full4096 F32 winner per actual encoder/input**, then derive
one normalized1024 representation shared by initial ANN and analytics. Full4096 supports bounded
candidate rescoring and numerical references. E1 neighbors, centroids, pairs, passage links and
community labels explicitly consume the declared1024 projection; they do not inherit a dimension
from the service client's current output. A full4096 analytical experiment has a different policy
and fresh results, not a silently changed E1 baseline.

Initial projection algorithm: take the first1024 admitted F32 components, accumulate squared norm
in F64, reject nonfinite/zero norm, normalize and round each result once to F32, then apply the
shared vector validator. Record algorithm, precision, dimension and source-value digest. This is
not guaranteed bitwise parity with endpoint prefix-before-normalization. All consumers share the
same derived bytes. Live numerical agreement is a separate bounded control.

| Identity | Change propagation |
|---|---|
| Encoder realization and exact final input bytes | Re-encode affected actual inputs; include checkpoint/tokenizer/quantization/build/pooling/output semantics |
| Render/partition and source/binding mappings | Rebuild affected windows/occurrences; identical final encoder input may reuse its winner |
| Query instruction/template | New query inputs and ranking realization; unchanged document values and E1 inputs remain reusable |
| Projection algorithm/dimension/precision | Derive from admitted full bytes without inference; rebuild dependent indexes and analytical results |
| Analytical method/input policy | New affected E1 results/receipts; no query-policy dependency |
| Analyzer/candidate/fusion/scorer/packing policy | New physical/query/delivery realization and continuations; not an encoder-wide invalidation |

An input label alone is insufficient; hash the actual canonical recipe and bytes. Canonical
consumption binds exact winners and explicit projections. Query values follow the same encoder/
projection semantics while retaining their own recipe and input identity. Source provenance belongs
to semantic uses and cannot unnecessarily defeat value sharing.

Update launcher admission and installed pooler configuration, both clients, cache admission,
canonical value/consumer declarations, graph/inventory/frontier registration, transport, schema,
search lowering, analytics and restore as one complete consumer migration. Current1024 bytes
cannot reconstruct discarded components. Native numeric arrays/indexes are derived; full winning
bytes and consumer identities replay without the mutable cache or live endpoint.

### 2.3 Native discovery, bundles and execution fit

Native SurrealDB querying is selected. Initial channels are exact identifier/option paths,
code-aware lexical matches and HNSW over1024 projections. Match eligibility does not require
positive BM25: retain zero-score literal matches through a bounded deterministic match route,
without inventing a relevance bonus. Positive scores remain heuristic rank contributions.
Use class/camel-aware analysis with exact original spellings separately; inspect actual configured
tokens for snake/camel case, acronyms, Unicode, qualified paths and option keys.

Nomination retains exact window/context witnesses. Aggregate distinct target/context alternatives
before final result limits and retain best contribution per family/channel/compatible context.
Within-family RRF K60 and equal family weighting remain the initial declared policy; full4096
rescoring reorders retained vector candidates, not missing candidates. Exact path priority and
canonical ties remain explicit. Bounded widening tiers128/256/512/1024 are initial experimental
ceilings, stopping when demanded distinct contexts are represented or the tier is exhausted.
No raw cap establishes complete absence or exact global top-k.

Initial search lowering has one derived projection row per distinct projection/library-release/family
cohort, with typed indexed scalar scope fields and the1024 array. Full values and canonical projection
bytes remain shared; no array is copied per target/window/anchor. The bounded cohort copy buys
selective native access at a deliberate write/index cost. Choose access paths by the supported
predicate. Covered scalar cohort predicates enable native bitmap prefilters and the engine's
small-set exact tier; verify the actual composed shape rather than assuming coverage. Relational occurrence/
binding predicates may remain residual. For a small exact eligible set, native distance scoring
is a valid route; broad discovery uses indexed ANN with honest approximation. Do not duplicate
full values per occurrence or enumerate the graph in Rust to produce engine-work counts.
Inspect representative EXPLAIN shapes at implementation to settle the actual scope route;
an index hint or correlated predicate is not evidence of bitmap execution.

Named native expansion batches semantic frontier restrictions, retains qualifications and
contradictions, and hydrates rich evidence late. Pack compatible context-closed alternatives
using the actual final renderer cost while preserving required identity/signatures/qualification.
Greedy selection is heuristic, not optimal/submodular. Return limits, omissions and expandability
truthfully. A candidate ranking witness is never requirement support.

For ranked continuation, pin a bounded candidate ordering and its retained query-vector digest,
channel/fallback/tier/scorer/packing policy and snapshot in a NativeSession-owned immutable result
entry. Initial retention is at most16 entries/8MiB per session with10-minute expiry; evict expired
then least-recently-used entries. The cursor carries the entry identity/digest, session identity,
request/policy bindings and offset, not the whole candidate pool. Expiry/eviction/session restart
returns explicit continuation-unavailable; it never reruns with a different ordering. This small
bounded cache has the actual pagination consumer and no durable query-history/registry service.
Original/section references retain their separate realization-pinned contracts. A new search
creates a new result; return expiry semantics in the generated output contract.

Workload: one local operator, immutable pinned releases, skewed windows/degree, concurrent native
reads and bounded optional inference. Root construction uses bounded batches and shared preparation;
values and projections are shared; inference happens outside transactions; scoped indexes and
late hydration avoid whole-graph copies; larger numerical references run offline in blocks.
Protective limits do not substitute for these work shapes. No accounting service, cost proof,
mandatory benchmark or ANN-backend adoption contest is required.

## 5. Verification, change scenarios and retirement

Targeted acceptance challenges meaning at each actual boundary:

- A page describes sibling A/B; an A primary window nominates A only, with B setup/navigation
  separately qualified. Re-export source differs from access module; ambiguous/non-callable roots,
  options, standalone documents and release deployment remain reachable.
- Complete tokenizer input includes Unicode, synthetic headers and mandatory setup. Source offsets
  survive rendering; an oversized indivisible unit remains honest and expandable.
- Query-template change reuses unchanged document winners and E1 inputs. Encoder changes invalidate
  values; projection changes derive without inference. Tiny independent numeric cases catch
  zero/nonfinite norms, wrong dimensions and receipt/source mismatches.
- Match-zero identifiers remain discoverable. Many windows for one API do not erase another target
  before contextual aggregation. Scope excludes a globally nearer foreign vector; actual native
  exact-small/ANN-residual routes retain eligibility and truthful approximation.
- Incompatible variants cannot combine signature/default/example. Qualification removal with its
  ID retained fails immediate sufficiency. Alternate independently valid witness routes succeed.
- New canonical records survive export/import/restore with complete registration. Missing companion,
  wrong derived binding or altered array refuses; restored indexes rebuild from full values without
  inference. Final SDK/MCP bytes enforce actual limits and pin safe expansion/continuations.
- A new configuration-precedence view extends source/binding/render/evaluator meanings locally.
  Replacing HNSW with exact eligible-set scoring changes numerical policy, not applicability or
  private expectations. Outer usability failure may change navigation and a new evaluator stratum
  without falsely relabeling an old formally sufficient packet.

Use pure model/provider controls where sufficient, selected real persistent RocksDB/native controls
where necessary, and actual editable-extension MCP controls for transport. No mocked provider pass
establishes live readiness. Plans choose release-profile family filters and applicable leaves once
at functional scope end; broad gates and stopped historical tests do not become acceptance here.
EV2 protects oracle sensitivity independently of producer/serializer validators.

Fresh current formats only. Recompile from pinned source and fresh full encoder inputs; re-admit
canonical graph/value content and rebuild derived projections/indexes. Quiesce affected readers
before replacement, validate the new current realization, then delete replaced readers, caches,
runtime copies and compatibility-only paths. No dual writer,1024-to4096 fiction, old-format reader,
rollback epoch or permanent experiment archive. Active comparison packets/minimized fixtures have
named current consumers. Gold/confirmation/heldout remain protected.
