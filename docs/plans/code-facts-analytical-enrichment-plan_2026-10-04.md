correlated diagnostic-use evidence, bounded supported import access paths, contextual Expected
arguments, incoming references, precise uncertainty and independent finite analytic oracles.

successful applicability; bound-unattached evidence is not an Entry proof. No second assignability
engine, alternate export resolver or generic recursive graph interpretation is selected.

`lctx-surrealdb` and `lctx-publisher` realize them; `lctx-serving` and the thin PyO3/MCP adapter
provide immutable native packets. Native detached import performs necessary owner admission; it
does not replay all producers or inherit historical validation receipts. The current design and
[validation owner](../design/sections/validation-and-evaluation.md) govern controls.

precise identity transfers and independent expected answers, including conditional/generated,

bundle does not establish packet benefit, live-Qwen usefulness or operator activation. The current
remediation's R-Q0 does not silently activate Q1.
