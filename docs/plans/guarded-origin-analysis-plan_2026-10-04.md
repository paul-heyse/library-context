## 1. Intended question and current proof boundary

The useful first answer is “Which definitions can reach this exact read, and why cannot we establish
its original parameter value?” A further answer, if actual native supply warrants it, is “Under this
read's admitted native access condition, only the original parameter can reach.” This is a bounded
extension of Entry origin, not general heap/alias flow or arbitrary caller-selected guard evaluation.

Current `conditions/entry.rs` resolves owner/formal/read/context/run and admits
`EntryAccessSource::Use/Value/Guard`. `DerivedEntryValue` is qualified; `EntryValueWitness`
retains the selected reaching row and complete attributed per-use inventory/support under

pre-test Guard source; Value/Use proof does not supply it. The integrated named-origin repair
uses a canonical native containing region when necessary to prove read-domain implication,
and retains its support and condition through alias publication. It does not admit competing
origins. A future guarded witness still requires the distinct conditional theorem and complete
multi-alternative evidence described below.

The current ty flow exporter retains Unbound for Undefined/Deleted and separates reachability from
narrowing. It can prune false candidates, expand loop headers into no rows and omit unattached or
unsupported definitions/conditions. Global CompleteUnderStatedModel Flow coverage does not establish
complete alternatives for one selected use. An exact candidate-list digest of visible rows alone
cannot fix this. The first prerequisite is per-use **attributed enumeration and lowering closure**.

Source routes: `crates/cpg-flow/src/lib.rs` use and loop binding enumeration;

### Publication and first consumer

## 4. G2 — Derive a distinct guarded-origin authority

**Working prerequisite:** replayed complete G1 inventory, plus the real useful native G0 case.
Reuse `EntryRequest` and existing admitted **EntryAccessSource::Value**. Derive Q from the exact
FlowValueObservation and same-owner FlowRegionObservation using the current Entry source operation.
No arbitrary submitted BDD, guard string, “true arm” reinterpretation of pre-test Guard, or narrowed
type predicate may select the domain. The Local value kind and original identity read must be admitted.

Introduce a distinct opaque derived authority and nominal guarded-origin witness. Conceptual fields:
owner/formal/read/context/run, exact access source, complete inventory/digest, original parameter
placement/declaration/link/support, chosen definition identity, every candidate premise, exact source
view and output qualification. Reuse shared source/formal/run/condition admission helpers, never
construct the current singleton authority by bypassing its private constructor.

For admitted candidate reaching conditions C_i, the owned operation must:

1. Require exact reachability and non-false Q under the existing condition model. An empty domain
   yields explicit EmptyNativeDomain, not a vacuous forwarding proof.
2. Resolve one exact original source parameter definition through current owner/formal/placement
   checks. Multiple evidence members for that identity retain full membership; conflicting definition
   identities are unresolved, never first-row selection.
3. Establish `Q ∧ OR(parameter conditions) == Q` and `Q ∧ C_i == false` for every non-parameter,
   Unbound or Nested competitor. Do not ignore an inconvenient candidate or substitute narrowing.
4. Refuse loop-carried/header or unresolved candidates in the first lane, even if a displayed
   predicate appears to exclude them. Approximate/lost reachability and failed atom lowering block
   proof. Family coverage stays separately scoped and is not upgraded by one successful inventory.
5. Preserve evaluation-occurrence atom identity and assumptions. A changed flag or same-spelled test
   at another evaluation cannot inherit exclusion without independently admitted stability/rebase.

Outcomes distinguish Proved, EmptyNativeDomain and Unresolved with precise evidence/obligation;
resource/cancellation failure follows the existing budget/error route. Charge candidate decoding,
indexing, atom alignment, every BDD operation, evidence membership and retained result before work
or allocation, using the current bounded kernel. Budget refusal is never false or unknown success.
Canonical production and replay use the same operation and definition identity includes its source.

The independent domain control has parameter condition `not a`, rebind condition `a`, Q=`not a`:
proof is expected. Q=always with the same complete inventory must be unresolved. Missing alternative,
wrong atom occurrence, overlapping Unbound, false Q, foreign frame, loop/partial conditions and
forged witness fail. This proves semantics independently of the revealing native fixture, which
separately establishes real supply and usefulness.
