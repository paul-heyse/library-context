## Context

The analytical-architecture review found useful retained facts without bounded product consumers,
and a native overload trace that erased original member identity. The operator authorized the
[analytical-enrichment coordinator](../plans/code-facts-analytical-enrichment-plan_2026-10-04.md).
The current model, native sources and consumers are Interface-checked, 2026-10-04. This decision
selects bounded enrichment; it does not certify implementation or assembled qualification.
ADR-0117/0118 continue to own independent analyzer families and immutable supply.

## Options

1. **Retain unavailable answers.** The simplest integration, but leaves supported source fields,
   callable roles, contextual typing, incoming references and native origins inaccessible.
2. **Interpret facts in packets or Python.** Shorter local changes, but creates independent
   classifiers, shape-based identity and hydration-dependent truth. Rejected.
3. **Model-owned finite operations and attributed native observations** (chosen). This requires
   exact inventories, shared replay, generated wire changes and matching adapter qualification.
   It localizes semantic change and keeps database and Python effects outside interpretation.
4. **Production ty reference or odis replacement.** Both offer richer algorithms, but their
   current batch allocation/work contracts do not preserve the charged production attempt.
   Select independent development oracles; retain existing production authorities.

## Decision

Rust model operations own role comparisons, source constructor/reader relationships, diagnostic-use
correlation, access-route interpretation, Expected-context explanations and captured incoming name
references. Existing generation-pinned selectors, opt-in sections, bounded continuation and original
proof expansion carry their results. Exact nominal identity is required; interface layout, typing
selection and source association do not grant runtime execution or binding authority.

The minimally patched Pyrefly supplier may retain original FuncDefId and call-local candidate ordinal
before callable erasure. Observation state distinguishes actual selected member, ambiguous or expanded
representative, closest-only recovery and resolved callable. Legacy checker selection/types/diagnostics
and IDE getters remain unchanged. Representative states cannot produce a unique association. Missing
receiver or solved specialization correspondence remains unavailable; TParams is not a solved table.
Original member identity joins native signature metadata origin and normalized variant under their
existing context, role and owner contracts. Equal shapes or ordinals never establish correspondence.

Per-use flow enumeration is attributed native evidence with conservative closure and full retained
candidate membership. Existing conditional Local proofs retain both call and value qualifications
through Structural composition/replay. Guarded multi-candidate proof requires the coordinator's native
usefulness trigger. Native enumeration closure does not certify complete Python semantics.

## Consequences

The target adds useful source answers without a new semantic provider, database or arbitrary fact
browser. New packet/model identity invalidates stale adapters. Query-local indices and result buffers
remain charged; full evidence is hydrated before paging. Original/runtime views stay distinct.
Ty references and odis are pinned development-only oracles with fixed small contexts and explicit
production non-fit. Licensing is not a rejection criterion; odis has a scoped dependency-policy
exception. There is no production algorithm replacement or performance claim.

Implementation and focused tests are in progress. Coordinator §7 owns status, conditional decisions,
source-qualified findings and Q1 full gates. Real-library reconstruction and operator activation remain
stopped. Acceptance of this decision alone closes none of those obligations.
