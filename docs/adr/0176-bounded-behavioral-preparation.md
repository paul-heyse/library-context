## Context

The [efficiency review F05/F06/I05](../design_review/reviews/design_review_catalog-completion-efficiency-target_2026-10-15.md)
identifies repeated Base syntax and Summary correspondence preparation, and asks whether expanded
analytic products should change. These are private preparation decisions: the model continues to
own meanings, proofs, work admission and coverage. The [coordinator §6](../plans/catalog-efficiency-plan_2026-10-15.md#6-sole-disposition-and-current-checkpoint)
owns delivery and actual acceptance. Behavioral execution remains explicitly requested.

## Options

1. Prepare each Base root and Summary attempt independently. This has a simple resource boundary
   but repeatedly builds the same immutable correspondence for overlapping roots/signatures.
2. Share bounded invocation preparation, preserving independent root/attempt consumers. Selected.
   Existing charged owners, DataFusion spill and schema-checked IPC provide local reuse without
   adding persistent invalidation or another semantic authority.
3. Retain every disjoint rich closure in one cohort, retry failed native acquisition, or cache
   rich prepared state across invocations. These respectively exceed singleton feasibility,
   replay submitted operations, or require new lifetime and context authority. None is selected.
4. Elide expanded analytic pairs or replace FCA/graph algorithms. Current published pair,
   concept, lattice and evidence consumers need those products; no equivalent complete replacement
   is established. Remove redundant preparation while retaining the exact kernels and products.

## Decision

Base selects at most32 compatible ordered roots under one exact input/frame. Discover each root's
membership at the existing singleton grain and spill primitive membership rows immediately. Capture
each unique supporting rich row once, at the grain of its first consuming root. Complete original
reads and schema checks before using private capture; preserve source owners and submitted failure/
Unknown finality. IPC is invocation preparation, never completed or published authority.

Adapt only pure local typed/syntax assembly and unconsumed root computation when its resource
admission refuses. Keep the immutable source lifetime borrowed through shared syntax consumption.
Partition every lookup by root membership; shared inventory cannot supply an unselected premise.
Root work, context, evaluation and proof identity remain independent. Adopt expression results
failure-atomically before emission. Native emission failures are terminal; do not replay them.

Summary builds one charged borrowed ordered inventory per exact invocation and lazily shares
immutable signature ingredients. Retain all competing rows and original first-use error gates.
Caller-bound ports, binding, admission, pair outcomes and proofs remain independently owned.
Release correspondence after its last SCC/pair consumer. The existing graph schedule, worklist,
Pareto frontier and residual semantics remain unchanged.

Analytics retains PairContribution, LayerPair, CombinedPair, concept/lattice evidence and the dual
FixedBitSet FCA representation. A private admitted ordered-count/universe route avoids redundant
vector/map/sort preparation; the checked public adapter uses the same kernel. Preserve isolates,
touched universe, deterministic order/seed, Leiden policy and exhausted-layer semantics.

## Consequences

Overlapping roots and repeated signatures reuse immutable preparation while their proofs remain
locally reasoned. Disjoint roots do not require simultaneous rich retention. Base capture adds
temporary IPC write/read work and can observe a later selected root's source failure before an
earlier root is emitted; it does not hydrate unreachable companions. Files are RAII invocation
outputs under the enclosing run/storage owner and release after their final local consumer.
There is no new cross-invocation cache or permanent data representation.

The current source implements these routes. Focused controls and independent source assessment
do not establish enclosing acceptance; native reconstruction and CE90 remain with the coordinator.
No measured throughput, memory-capacity or timing improvement is claimed.
