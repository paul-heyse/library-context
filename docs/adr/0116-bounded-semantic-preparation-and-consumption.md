## Context

The incremental alignment review exposed duplicated semantic preparation in storage, closure
walks and policy literals, open orchestration routes and independently authored packet metadata.
The accepted alignment target corrects these seams while retaining the single relation model,
PostgreSQL generation lifecycle and existing finite analysis meaning. The
[coordinator](../plans/semantic-model-incremental-alignment-plan_2026-10-02.md#7-current-disposition--sole-execution-owner)
owns F01–F08 and O1–O6 implementation acceptance. This refines ADR-0108/0114; their original
guard, canonical evidence admission, numerical boundaries and qualification obligations survive.

## Options

1. Keep semantic joins and metadata in effect adapters. This is locally simpler to edit but
   independently reauthors causes, dependencies and settings across consumers.
2. Use ordinary typed model operations, a finite executable binding and exact requirements
   lowered into sufficient grants. This keeps current mechanisms and makes each meaning have
   one owner with independent store/transport admission.
3. Add general executor/preparation/projection frameworks or detached owned CPU workers. Their
   new configuration, lifetime and recovery obligations do not resolve another demonstrated need.

## Decision

Select option 2. The model prepares opaque native semantics and the valid public formal domain
from explicit typed inputs and borrowed selection data. Storage hydrates exact receipt-bound
inputs, executes shared invariants, checks actual stored proof membership and reconfirms the
original guard. Valid defaulted formals preserve their exact refusal rather than becoming foreign.

One fixed analytic policy supplies persisted parameters, complete semantic identity and kernel
arguments. A closed compiler binding supplies phase, declaration, publication groups, graph needs
and runner. Shared model closure preserves exact relation/epoch/order requirements separately
from one sufficient grant, comparing scheduler publication ordinals. Actual consumers retain
independent acknowledged sources and ordered validators.

CPU kernels borrow charged inputs through synchronous blocking regions on the multithread
runtime; other contexts explicitly run inline. Independent operational sampling holds no semantic
access. Kernels drain before borrowed access/charges release. S0 shares only the three common
analytic parents; replay owns its independent inputs.

Typed packet output bindings compose direct sources, child outputs and prepared dependencies.
Finite immutable declaration metadata is shared; attempted reads, including empty requests,
check permission before effects. Dynamic proof capability names the canonical relation universe,
while actual canonical membership/receipt checks remain independent. Discovery mechanically
labels numeric codebooks and exposes model descriptions. Fixed coarse public failures can use
one complete envelope admitted on the original grant and ID; refusal falls back once through
existing safe pinned tool/resource behavior.

Inferred ordinary fact invariant premises remain exact validation requirements, while grant
projection relies on the admitted, frozen Facts checkpoint for those premises. Direct consumed
facts always retain grants. Store input admission refuses missing checkpoint coverage; Catalog
Flow remains NotRequested with no Flow writer or fabricated source receipt.

## Consequences

These routes are Implemented, 2026-10-02, with focused controls and independent source review
recorded in the coordinator. Architectural acceptance alone does not close findings. No new
semantic feature, general registry, compatibility path or stronger behavioral guarantee is added.
Policy and composition edits rotate model/schedule/native/mapping/wire identities; operational
measurements do not enter content. Old state must be retired and rebuilt before activation.

Inline placement has no responsiveness claim. Opaque CPU work is not forcibly cancellable.
Guard loss, deadline or budget refusal may prevent failure-envelope admission. Universal early
error bounds need a separate transport request-limit decision. Speed and total RSS are unmeasured;
real-library Q0 and activation remain stopped. Reopen only at the stated consumer/lifetime/error
boundary, rather than broadening this increment into an overhaul.
