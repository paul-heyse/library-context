## Context

The [populated journey review](../design_review/reviews/design_review_populated-journey-execution-amplification_2026-10-08.md#f01)
identifies vocabulary-wide native body/scope programs and repeated final membership preparation.
The operator accepted its RC01/RC02 and retained native placement and SQL staging transport.
The [companion](../plans/populated-journey-execution-amplification-plan_2026-10-09.md) and its
[independent target review](../design_review/reviews/design_review_populated-journey-execution-plan_2026-10-09.md)
define the correction. Existing persisted code and receipts are foundations, not qualification
of this changed enforcement/lifetime boundary. This record consolidates the surviving ADR-0128, ADR-0133
and ADR-0135 contracts; only broad native semantic-body enforcement and scope VALUE replay change.

## Options

1. **Retain native closed unions and stored scope VALUE.** Immediate database shape rejection,
   but unrelated vocabulary expands ordinary write preparation and dispatch. Pointer reuse alone
   corrects repeated final selection without correcting this coupling.
2. **Fixed envelopes with typed ingress and full independent reconstruction (selected).** Existing
   model callbacks validate actual records; native constraints retain envelope/index/endpoint
   obligations. Derived scopes and compact final runs amortize invariant preparation. Deliberately
   loses standalone statement-time rejection of arbitrary private raw-SQL semantic body defects.
3. **Discriminator ASSERT or per-kind tables.** Retains database closedness at the cost of another
   validation program or vocabulary-proportional definitions/index/routing. No named consumer
   currently earns that burden.
4. **Mutable generation cache, alternate intermediate store or data-only restore.** Adds
   invalidation/placement/transport obligations beyond the selected immutable final-read lifetime.
   Retain these alternatives only with the companion's concrete revisit triggers.

## Decision

Rust lctx-model remains the single authority for typed nominal records, attributed assertions,
roles, source correspondence, uncertainty, canonical identity, domain operations and invariants.
Every compiler frontier/profile, including artifact-only, uses one private STRICT native database.
Pending contribution rows never widen exact immutable completed views. Complete-empty output,
availability and optional outcomes remain explicit; full keys and full payload equality own
conflict/deduplication. Preserve exact predecessors and answer-affecting source/model/settings,
captured supplier/specification and implementation inputs, including absence-sensitive universes.

Keep one immutable native canonical owner for graph payloads, canonical bytes and complete bodies;
non-graph products use declaration-derived compiler backing, originals their existing chunk owner.
Use fixed SCHEMAFULL envelopes with flexible object bodies and supplied typed scope fields.
Selected declaration-derived synchronous adapters validate and lower bounded windows before
writes, preserving local sum rules, field presence, NULL/bytes/text, scopes, aliases and originals.
Independent cold/publication admission reconstructs complete expected physical rows and compares
actual envelopes, bodies, scopes, graph/state and originals. Private raw SQL is not a supported
semantic writer and cannot confer admitted validity.

Final artifact admission irreversibly freezes compiler content. The Workspace completion gate
fences native completion, binding persistence and visible descriptors; close/drain admitted content
mutation, establish exact descriptor agreement, then attest and semantically admit that frozen
state. Normal compilation and independent restored-manifest provenance remain distinct. Reads
stay available until final global drainage. Prepare complete alias-aware compact entity/assertion
pointer runs once; independent charged cursors retain scratch through actual worker terminality
and the last consumer. Preparation is derived selection, never proof of body/semantic validity.
Compiler-owned sessions expose no unrestricted admin-client escape. Publisher's supported
publication API accepts only private-constructed admitted artifacts or restored admissions,
bound to their exact native store and manifest. It owns a separate private authenticated effect
session under native lifecycle guards: derived edges/search/definitions, then global drainage
and one final seal. Physical freeze provides immutable reads and preparation, not a publication
entrypoint. Native guards expose no seal, marker writer or administrator. Explicit standalone
Loader/admin SQL remains privileged mechanism access, not semantic admission or a supported
publication workflow. Canonical mutation remains closed. Already admitted read descendants
finish under their retained parent during global closure; new reads are refused. Marker
acknowledgement stores the exact committed identity in the retained native owner before any
later await, so cancellation cannot erase a known publication.

Ordinary publication seals the same admitted native result without self-export/import/re-ingestion.
Detached external artifacts retain independent transport/readmission, then publish their admitted
native authority without another canonical reload. Complete SQL backup/restore retains executable
staging isolation, fresh reconstruction, originals and contribution/view/binding/backing state
across physical names. Deterministic graph-family and completed-state content identities remain
separate in the manifest. Keep completed-state format2, artifact format3 and v2 contribution/native
content digest domains; rebuild obsolete realizations rather than introducing compatibility readers.

Carry forward structured model-owned operation outcomes: primary/secondary failure, local
terminality, remote certainty, private disposition and committed effects. Workflow owners drain
and finalize. Unknown acknowledgement fails the attempt; a later cleanup failure cannot roll back
an already committed publication/backup. Captured supported producer/configuration/source bindings
remain distinct from current executable provenance; cold admission independently selects supported
contracts and all nine facts premises. No invented supplier/current-default replacement.

Native access retains table-specific scope/index meanings, prepared bindings/result positions,
terminal streams and compact external ordering before exact membership and bounded hydration.
No whole-match arrays, growing union dedup set or new DataFusion runtime per scan. Parser-owned
whole SQL import units aggregate into checked sequential bounded HTTP requests. A failed request
can have later private effects; no subsequent request executes, and cleanup reports certainty.

Dependency direction remains cpg-core -> lctx-surrealdb -> lctx-model. Mechanisms own native
storage/finality; core owns orchestration/admission; publisher owns visibility. Pure finite model
and analytical kernels accept explicit values without a database; Arrow/DataFusion is compute
and transfer, not another canonical authority. Preserve available compiler/runtime/test workers.
No transaction spans extraction, CPU computation, inference or external files. Selection is
separate from publication; readers pin one complete semantic/executable realization under VIEWER.

Retain pinned acquisition, provider attribution/disagreement/coverage, programmatic assertions and
primary evaluation, complete embedding values/specifications with explicit projections,
append-only codebooks, terminal streaming and fresh rebuilding from pinned inputs. Cross-run
invalidation/execution remains deferred; no event ledger, retry executor or resumability grant.

## Consequences

An unrelated record extends declarations and selected adapter metadata without expanding existing
row DDL/body/scope programs. Final read consumers share compact preparation without mutable cache
invalidation. Scratch/cursor charges, frozen content ownership and complete physical validation
remain substantive implementation obligations. Flexible bodies deliberately weaken raw-SQL local
rejection; independent admission remains fail-closed. Coarse phase evidence uses existing logs,
not a telemetry service. Quantitative speed or capacity claims require representative measurement.

This decision is **accepted at Proposed implementation strength, 2026-10-09**. PJ0-PJ5 and the
[persisted coordinator](../plans/persisted-graph-execution-plan_2026-10-07.md#8-sole-finding-disposition)
own migration and evidence. F01/F02 remain open until their controls support closure; F03 and
retained larger alternatives remain triggered deferrals. Existing PC/CU/BC qualification gaps and
operator-deferred timeouts remain separate. No operator activation, real-library/protected
qualification, wheel, benchmark campaign or push follows. No old-format reader, dual canonical
store, legacy-ID bridge, rollback asset or historical runtime archive is introduced.
