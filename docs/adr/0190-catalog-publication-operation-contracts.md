## Context

The publication performance review F01–F12 identifies repeated rich acquisition, exhaustive
attempted-pair persistence, repeated preparation/copying, per-row protection and per-window
recovery machinery. The operator approved RC01–RC10 on 2026-10-17 and separately approved
operation-local authentic executed whole-input reuse during execution planning. The
[publication coordinator](../plans/catalog-publication-performance-plan_2026-10-17.md#6-sole-disposition-and-current-checkpoint)
owns implementation and verification; acceptance here does not establish either.

## Options

1. Retain current exhaustive traces, borrowed emitters, per-row objects and per-effect host
   envelopes. This is mechanically familiar but makes logical kind and candidate counts multiply
   persistent work without a supported consumer. Larger windows alone leave that amplification.
2. Prepare operation-shaped inputs and output packets, persist sufficient semantic products and
   protect shared physical blocks/pages under existing owners (selected). This preserves selected
   access and independent receiving while reducing reconstruction and lifecycle participants.
3. Fully packed unindexed data or one compilation-wide transaction. These lose selective access
   or broaden live state, conflict and recovery scope. A global cache/pool would add authority
   and invalidation machinery without closing the actual gaps.

## Decision

### Semantic and execution preparation

Keep dependency/coverage authority distinct from actual payload demand. Invocation-owned
preparation binds exact views, ordered requested/resolved roles, model/profile/context, original
pins, resource and cancellation owners. Necessary whole/negative universes remain complete.

Summary owns a private deduplicated question domain from processed current candidates and
residuals, independently of persisted attempted-pair traces. Existing finite witnesses and
residuals suffice for member evidence. Caller qualification, qualification-independent refusal,
exact proven qualification and original operand correspondence remain unchanged. Diagnostic
replay reconstructs questions independently; it does not become ordinary admission. Candidate
visitation, finite work/member accounting and SCC progress remain canonical.

Consume charged canonical output after its last semantic use. Integrate ready canonical private
prefixes through actual registered jobs; later failure poisons completion and joins descendants.
Required readiness may precede optional retention only when an independently owned retention
child protects its exact source/budget and the enclosing operation joins accepted outcomes.
This replaces the retention-before-readiness ordering within ADR-0174's otherwise preserved
coherent composition, source protection and finality contract.

Private whole-input reuse is earned only by complete successful registered execution over actual
exact native inputs. Bind invariant/factory/model/profile, ordered roles/views, ledger/frontier,
original pins, operation/executor/cancellation/resource context. Commit reusable successes only
after the complete validation attempt succeeds; failure invalidates them. A digest memo, external
mutable planner, nominal Execution label or equal replacement pin is insufficient. Independent
receiving and final mutable-state/eligibility checks remain required.

### Native realization and recovery

Nongraph canonical envelopes use globally content-addressed versioned blocks with indexed,
contribution-qualified logical locators. A 256 KiB encoded packing target is not a new row limit.
Full equality resolves address agreement; selected-view nominal conflicts remain distinct from
independently valid views. Logical IDs are preserved but are not physical guard/retirement
addresses. One contribution-to-block hold uses existing incarnation/new-reference exclusion;
contained rows acquire no redundant hold/guard. Selected slots determine semantic membership.
Graph adjacency and original-byte authority remain native. Logical export reconstructs envelopes;
physical recovery inventories actual objects. Pure packing preserves logical state format4;
the new physical/control generation is10, regenerated rather than read through legacy paths.

Prepare complete bounded installation packets once, retaining original request identity and
declared incidence. Set observation does not replace scalar commit-sensitive locks. Retain one
durably discovered operation root per actual ingress and exact native page receipts/progress.
Root creation and absent-root fencing contend on the same identity. Each page atomically commits
payload/incidence/outcome/bounded progress; old receipts stay replayable. An absent-page fence
stops suffix advancement. Never replay Unknown with a new identity or reconstruct production
payload after host loss. Durable terminal knowledge precedes last-witness release. This replaces
ADR-0178's per-ordinary-page host-envelope realization only; its actual executor, cuts, strict
equality, exact recovery, Unknown and campaign obligations continue unchanged.

Terminal cleanup uses exact reference/history/collector hazards after permanent production
fencing. Keep genuine full freeze/close/admission cuts. Nominate shared content before releasing
retaining holds. Borrow actual SDK sessions; deliberate independent sessions close explicitly.

### Public publication

Demand only required definition details and retain operation-local interpretation under actual
installation/epoch/client/exclusion ownership; retain final observation for unprotected mutable
premises. Prepare charged canonical/role/search expectations once, with fresh independent actual
content/root reconciliation at seal. This refines ADR-0156 preparation, preserving its role
meaning, marker guards and independent incoming/restore reconstruction. No incoming serialized
carrier supplies private authority. A committed marker remains committed if later cleanup fails.

## Consequences

The selected design removes unnecessary work while keeping semantic, admission and native
ownership separate. It requires complete reader/writer/audit/recovery migration, revealing
functional failure controls and owner-authenticated schema cutover. No throughput or memory
improvement is Measured by this decision. Existing unresolved native obligations retain their
owners; new-generation success does not release them. Existing older plans remain unchanged.

Reopen a specific contract if an actual consumer needs exhaustive pair enumeration, selective
block access cannot satisfy its advertised predicates, or recovery cannot fence delayed original
work. Continue independent corrections without weakening those guarantees. The coordinator owns
focused implementation/verification and a separate later full-journey handoff.
