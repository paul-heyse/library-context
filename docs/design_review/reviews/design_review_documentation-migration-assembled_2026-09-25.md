## 4. Composition and execution

Not a runtime system. The composition that matters is the reading route: `docs/README.md` task
row → owner → `> Decision:` ADR → plan W-row → retained review anchor. Every hop is a link
checked by `docs-check`; ADR governance is checked by `adr lint`. Publication derives Current
and Reference collections from `docs/site.toml`; the History scope is gone (only the migration
plan's own prose mentions it in the built site).
