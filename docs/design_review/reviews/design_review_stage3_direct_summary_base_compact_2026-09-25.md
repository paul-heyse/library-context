The first producer uses unmerged raw value contributions, attributed return syntax and region, and the persisted structural BDD catalog. A positive row requires a synchronous function's direct body return, an identity source from its own parameter, no crossed call and no generator yield. The model path renderer supplies `Parameter[name]` and `ReturnValue`. Missing or capped condition structure becomes a named unknown; a false root cannot become a positive row. It intentionally leaves modeled calls, async/generator execution and nested control frames for later composition. On 2026-09-25 the focused Nextest selection (`contracts_snapshot`, `registry_snapshot`, `rules_snapshot`, `pinned_identity_models_require_and_publish_their_real_formals`) passed 4/4; targeted release-profile Clippy, `just adr lint` and `git diff --check` passed.
