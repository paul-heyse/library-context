## 3. Contracts, constraints and testing boundaries

`Prepared::new` retains authoritative broad C2 reconstruction and comparison. It then projects owned classification rows and creates charged indexes. `Prepared::from_local_rows` checks local finite integrity and grants no publication or PostgreSQL admission capability.

Classification helpers consume the narrow inventory. Required references remain distinct from references that an Unknown or unresolved branch never dereferences. The corrected checks preserve Unknown receiver applicability and unresolved scenario associations without promoting them to exact evidence.

`GenerationReader` requires serving-role configuration and uses the existing canonical lease protocol. `prepare_selection` requires a published Catalog frontier, matching admission and C2 validator receipts, consumed content hashes, applicable selection availability and complete captured source identity. It scans and verifies through the original leased connection.

`AdmittedSelection` retains owned rows/indexes, their reservations and that lease through shared ownership. Classification uses the same pure evaluator, with original-guard checks before and after computation. Guard loss is terminal. Missing/corrupt required evidence and resource exhaustion refuse explicitly; they do not produce an empty complete answer.

Pure finite semantics remain testable without PostgreSQL. Store integrity and lifecycle controls appropriately exercise actual disposable PostgreSQL.

## 7. Findings and applicable principles

### F01 — Ordinary inherited prefixes were conflated with publication-group membership

The initial `verify_selection_sources` implementation derived non-vocabulary source prefixes only from `publication_outputs`. Ordinary non-group outputs legitimately inherit the maximum acknowledged-input vocabulary prefix under `StageAccess::complete`. They need no explicit publication-group output row.

The actual Catalog run exposed this on `ancestry_entity_assessments` from `normalize_relations`, carrying a Facts prefix. The initial consumer refused a valid generation despite matching content and receipts.

**Principles:** FP-04/05, DP-02/03/08, A2, G2/G3/G6.

The correction preserves explicit group-output comparison. Only an ordinary non-group source uses its already-rehashed canonical C2 capture as durable inherited-prefix metadata, resolved against the generation’s finite registered order and checked closed group/schedule/physical identity. Producer and payload checks remain. Vocabulary sources receive no such fallback.

**Closure evidence, 2026-10-02:** independently inspected source correction and actual both-profile Catalog controls, including a wrong closed, FK-valid explicit group epoch with unchanged canonical payload/receipts. Functional closure is **Tested within these controls**. Current disposition belongs to the foundation plan §5.3.

No remaining material finding was identified. FP-01–FP-06 are satisfied for the selected scenarios. Applicable supporting rules concerning authority, typed distinctions, invariants, reuse, effects, resources, evidence and extension locality are satisfied at the stated scope and strength.

## 8. Library fit and total complexity

The implementation reuses established charged containers, standard maps/shared ownership, Tokio coordination, SQLx streaming, canonical codecs and the existing PostgreSQL lease protocol. Specialized code implements domain inventory, finite integrity and receipt interpretation.

The added machinery serves concrete consumers. It creates no dynamic row registry, universal workflow engine, fixture framework, alternate classifier or new store. Its costs are explicit inventory maintenance, retained index memory and canonical admission verification. Faster serving remains an unmeasured hypothesis.

## 9. Alternatives and tradeoffs

Keeping broad replay once per generation is simpler but retains producer inputs and couples admission to reconstruction. Indexing alone leaves that coupling. SQL predicate pushdown as another classifier duplicates applicability and incomplete-absence semantics.

The selected split retains the semantic evaluator and broad replay while giving generation preparation a smaller owned contract. Complete metadata preparation costs more than positive-witness slices, but preserves missing lookups and completeness. Revisit slicing only for a named workload exceeding the admitted envelope with a settled closure contract.

For F2/F3, ordinary owner methods and typed callback composition are sufficient. A global row framework would add machinery without improving the current boundary.
