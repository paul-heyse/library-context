## Contracts, alternatives and scenarios

The independently preferred target is an operation-shaped path: exact acquisition supplies necessary assurance/compact properties; complete selected dependencies key shared preparation; set/native processing reduces data before rich hydration; root identity survives discovery/hydration/rendering; pure kernels run in the appropriate execution owner; final publication and each receiver earn their own guarantees.

Increasing deadlines/workers preserves redundant work. Moving all analysis to SurrealDB loses useful existing pure/model/graph contracts without demonstrated benefit. A global cache adds invalidation/trust/lifetime burden. Fusing every stage can hide independent outcomes/admission and useful scheduling. Keeping every operation serial solely to bound memory does not establish execution fit; actual charged overlap is a viable alternative. No new dependency/upgrade was selected.

Existing projection/filter pushdown, lazy batched PreparedEdges, coalesced graph hydration, callee-first SCC schedule and borrowed/owned CPU routes are strengths. Exact equality, columnar positions and resource behavior still need implementation-specific qualification. The reviewer found no basis to replace Summary with database reachability.

Revealing changes/scenarios include adding a native family under one finite model inventory; adding a renderer without a second scope interpreter; replacing a physical selector while retaining independent admission; growing unrelated facts; overlapping roots; cyclic/high-degree calls; mixed epochs/equal IDs with different payloads; late failure/cancellation; concurrent grains/compiles with coherent deterministic output and actual owner drainage.

## Priority, open choices and prospective rule impacts

Remove redundant native acquisition, discarded C0 reads and retrieval amplification; qualify sufficient compact properties. Broader readiness and independent-grain overlap then shorten unnecessary serialization without multiplying redundant work. Pairwise agreement and retry scope matter under growth/capacity pressure; feedback improvement is separate.

Contracts/lifetimes precede dependent consumers and scheduling. Open choices concern shareable protected observations versus independent receiving, sufficient inventory validity, true epoch prerequisites, useful resource-owned overlap, exact grouped equality and actual timeout phase attribution. Small revealing controls/selective probes suffice where necessary; a full real-library campaign is not a prerequisite for selecting the target.

- **IRC01:** compact inventory borrowing changes the declared full-row consumer/admission contract and semantic owner; otherwise retain full validation where necessary. Principal RC03.
- **IRC02:** scoped admission replacing the normalized barrier changes the semantic owner/current realization; keeping it still permits safe private preparation and internal overlap. Principal RC01.
- **IRC03:** retry granularity changes the storage owner's contributor-preparation realization while retaining terminals/incarnation/receivers. Principal RC02/F02.
- **IRC04:** changing single-contribution writer order would require a separate decision. The proposed target keeps that order and overlaps private preparation/compute, so no such change is recommended.

These are prospective impacts, not approvals. No A2/fidelity/publication rule needs weakening. The review does not close PC90 upper evidence, native Unknown/cleanup, full qualification, operator adoption or excluded serving/embedding scope.
