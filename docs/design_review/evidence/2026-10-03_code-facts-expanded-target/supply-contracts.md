## Ruff: populated facts and the extraction seam

**Interface-checked:** [`ruff_linter/src/lib.rs:22`](https://github.com/astral-sh/ruff/blob/3265ed1f944c98bb4c04d632fbefb1257cdb583d/crates/ruff_linter/src/lib.rs#L22) declares private `mod checkers`; [`checkers/ast/mod.rs:195,233`](https://github.com/astral-sh/ruff/blob/3265ed1f944c98bb4c04d632fbefb1257cdb583d/crates/ruff_linter/src/checkers/ast/mod.rs#L195) has crate-private Checker holding `SemanticModel`. [`model.rs:208`](https://github.com/astral-sh/ruff/blob/3265ed1f944c98bb4c04d632fbefb1257cdb583d/crates/ruff_python_semantic/src/model.rs#L208) exposes constructor/mutators, but constructor initializes empty scopes/reference/binding collections and builtins, not a walked Python module.

[`check_ast:3490–3570`](https://github.com/astral-sh/ruff/blob/3265ed1f944c98bb4c04d632fbefb1257cdb583d/crates/ruff_linter/src/checkers/ast/mod.rs#L3490) constructs the borrowed module/checker, visits module/body, deferred nodes **in order**, exports, then analyses. It returns semantic-syntax errors, not the semantic model. Therefore simply linking the public semantic crate does not obtain populated bindings or per-node context.

**Proposed preferred seam:** pinned library-owned driver with owned fact callback/output; project source joins by bytes/provider ID. A scoped fork/export seam around existing Checker traversal is technically credible and preferable to copying its Python visit semantics. A final callback can project persistent scopes/bindings/references/shadow chains; per-expression runtime/typing flags and qualified-name answers need callback/snapshot **while current context is active**, including deferred visits. `visit_stmt:1003`, `visit_expr:1727`, snapshot/deferred/restore sites show why a final module-state inspection alone cannot reconstruct every contextual answer. The model borrows source AST/module paths; return owned projections rather than let borrowed model escape its allocator/checker lifetime. This is a design proposal, not a compiled seam; a visibility-only fork is insufficient if it provides no traversal hook. Alternative is an upstream API request; copying the full Checker is the least attractive route because it creates local Python scoping/visit-order authority. CLI lint JSON is usable for diagnostics but exports no equivalent populated model contract.
