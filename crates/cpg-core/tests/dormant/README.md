These files are not Cargo test targets (Cargo builds only `tests/*.rs` and `tests/*/main.rs`).
They retain independent serving expectations while Phase 5 is unavailable. Supplied typed P5
fixtures/generations must replace historical Delta/import setup; those mechanics never return.
No dormant source is a passing receipt or an active P4 semantic authority.

`test_value_paths.py`. cpg-schema query/wire/bundle/serving contracts and PostgreSQL services remain
preserved. These routes are recovery obligations; current P4 acceptance does not qualify serving.

pagination or hydration control. Its independent semantics moved to typed `domain_selection` /
`domain_selection_catalog`, `domain_catalog_evidence`, `catalog_selection` and `catalog_evidence`.
Likewise, P4 parts of PR4 rendering, spec/cache realization and classification moved to typed
retrieval/embedding/selection controls. The Phase 4 plan §11 owns the precise migration map and
qualification receipts. Pure P4 analysis/behavior/compile/graph/syntax/function-implementation files
and their old table-form snapshots are retired after that map; Git retains their historical form.
